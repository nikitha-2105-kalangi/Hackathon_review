JobTrack – Online Job Application Tracker

Your Career, Organized.

📌 Project Overview

JobTrack is an Online Job Application Tracker developed to help job seekers efficiently manage and organize their job search process. It provides a centralized platform to track job applications, monitor application statuses, manage interviews, set follow-up reminders, and view application statistics.

The platform aims to make the job search journey more organized, productive, and convenient through a simple and user-friendly interface.

🎯 Objectives

- Simplify the process of managing multiple job applications.
- Track the progress of applications in one place.
- Organize interview schedules and follow-up activities.
- Provide insights into job application progress.
- Improve productivity and reduce the chances of missing important opportunities.

✨ Key Features

- User Authentication: Login and signup functionality.
- Dashboard: Overview of job applications and their progress.
- My Applications: Add, view, and manage job applications.
- Application Status Tracking: Track applications as Applied, Interview, Offer/Selected, or Rejected.
- Interviews & Follow-ups: Manage upcoming interviews and follow-up activities.
- Statistics: View application insights and progress.
- Admin Module: Administrative interface for project management.
- User-Friendly Interface: Clean, responsive, and easy-to-navigate design.

⚙️ Installation and Setup

1. Clone the repository:

git clone https://github.com/nikitha-2105-kalangi/Hackathon_review.git

2. Navigate to the project directory:

cd Hackathon_review

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

5. Open the local URL displayed in your terminal.

🚀 Deployment

The project can be deployed using Vercel by connecting the GitHub repository and configuring the Vite build settings.
